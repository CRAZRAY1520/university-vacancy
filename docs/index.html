    計算方式

    • 核定名額：教育部核定的招生名額（含之後有人保留入學資格的部分）。可招名額 = 核定名額 − 保留入學，是註冊率的分母，也是圖表 1 的長條。
    • 缺額 = 核定名額 − 保留入學 − 實際註冊。每個系所班別各算一列，負值（超收）以 0 計，再加總。
    • 註冊率 = Σ註冊 ÷ Σ(名額 − 保留)。
    • 「最新學年」「起始學年」是學年區間滑桿的兩端；KPI 與散布圖的增減都是起始學年對最新學年。
    • 學校排名與散布圖不受「學校」篩選影響，被選取的學校會標示出來。
